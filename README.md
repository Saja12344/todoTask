# todoTask

A SwiftUI task-management application with local data models and Firebase-related configuration. The app includes task-oriented views, user models, notifications, and a Core Data model.

## Features

- Task and item management UI
- User and notification data models
- Persistent app data model
- Firebase configuration included for the app target

## Tech stack

- SwiftUI
- Core Data
- Firebase configuration
- Xcode

## Run locally

1. Open `todoTask.xcodeproj` in Xcode on macOS.
2. Select the `todoTask` scheme.
3. Select a simulator or connected iOS device.
4. Build and run with `⌘R`.

> Keep Firebase credentials and provisioning settings private when sharing the project.
